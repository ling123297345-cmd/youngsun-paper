Papel para etiquetas

Papel frontal imprimible para etiquetas y tags, seleccionado según el adhesivo y la línea de conversión.

Descripción del producto

El papel para etiquetas se utiliza como cara imprimible de materiales autoadhesivos, etiquetas con cola húmeda y tags colgantes. Los grados C1S, C2S y metalizados se seleccionan según el sistema de impresión, la construcción adhesiva, el troquelado, el desmallado, el rebobinado y el uso final. Los gramajes de referencia van de 60 gsm para aplicaciones ligeras a 250 gsm para tags estructurales. La velocidad, el curvado y la estabilidad dimensional deben validarse con el frontal, adhesivo, liner y ajustes reales de la línea.

Especificaciones

  • Gramaje: 60–250 gsm
  • Tipos: C1S/C2S/Metalizado
  • Acabado: Brillo/Mate/Semimate
  • Alta resistencia a la tracción
  • Formato: Bobinas y hojas

Aplicaciones

  • Etiquetas para botellas
  • Etiquetas colgantes de moda
  • Etiquetas de bebidas
  • Etiquetas de precio
  • Etiquetas de seguridad

Preguntas frecuentes de compra

¿El papel para etiquetas es un material autoadhesivo terminado?

No siempre. Esta página cubre papel frontal y papel para tags. Un material autoadhesivo terminado también incluye adhesivo y liner, que deben seleccionarse y confirmarse con el convertidor.

¿Conviene elegir C1S o C2S?

C1S se utiliza cuando basta una cara estucada para imprimir, como en muchas etiquetas. C2S es útil para tags impresos por ambas caras. Confirme impresión, adhesivo y acabados.

¿Qué información necesitan para cotizar?

Indique aplicación, grado C1S, C2S o metalizado, gramaje, brillo, impresión, adhesivo y liner si aplica, ancho de bobina o medida de hoja, cantidad y puerto.
